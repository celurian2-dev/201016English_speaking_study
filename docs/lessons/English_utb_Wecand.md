# 🗓️ 주말 이야기 영어로 말하기 (Weekend English)
 
> 영어 학습 스크립트 기반 **한→영 말하기 연습 노트**
 
## 📌 학습 방법
 
1. 🇰🇷 **한글 해석을 먼저 보고**
2. 🗣️ **영어로 소리 내어 말해 본 뒤**
3. 👀 **`영어 확인` 을 클릭**해서 영어 직역을 확인
4. 🔊 **발음 듣기**를 눌러 원어민식 발음을 따라 말하기
> ℹ️ 🔊 링크는 클릭하면 새 탭에서 음성이 재생됩니다 (Google 번역 음성 사용, 인터넷 필요).
